# kubernates

Project Overview:

This project demonstrates deploying and managing an application using Kubernetes. It includes Kubernetes resources such as Namespaces, ConfigMaps, Secrets, Deployments, Services, Persistent Volumes, and Persistent Volume Claims.

The objective is to understand Kubernetes resource management, application deployment, networking, and persistent storage.

Technologies Used:

Kubernetes
Minikube
kubectl
Docker


YAML Files Used:

namespace.yaml
configmap.yaml
secret.yaml
deployment.yaml
clusterip.yaml
nodeport.yaml
pv.yaml
pvc.yaml
storage.yaml


Prerequisites:

Make sure the following tools are installed:
Docker
Minikube
kubectl
